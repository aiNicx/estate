# Fotografie della proprietà

Carica qui le foto originali. Non è obbligatorio rinominarle: qualsiasi `.jpg`, `.jpeg`, `.png` o `.webp` in questa cartella va bene.

Se vuoi velocizzare il collegamento al sito, usa questi nomi (uno per ciascuna delle 8 foto già condivise):

| File consigliato | Soggetto |
| --- | --- |
| `01-hero-cove-aerial.jpg` | Vista aerea della cala e della proprietà (hero) |
| `02-architecture-hillside-aerial.jpg` | Vista aerea dell’edificio, terrazze e lettini |
| `03-terrace-dining-sea.jpg` | Terrazza con tavolo da pranzo e vista mare |
| `04-living-kitchen.jpg` | Soggiorno / cucina open space |
| `05-bedroom.jpg` | Camera con copriletto rosso |
| `06-bathroom-majolica.jpg` | Bagno con maioliche Vietri blu |
| `07-bathroom-geometric.jpg` | Bagno con doccia a piastrelle geometriche |
| `08-corridor-mosaic.jpg` | Corridoio con mosaico a onda |

Puoi aggiungere altre foto (`09-…`, `10-…`, ecc.). Evita HEIC (iPhone): esporta in JPEG prima del caricamento.

- Dimensione consigliata: sotto i 8 MB per file (limite GitHub: 100 MB).
- Non comprimere in modo aggressivo: servono per una presentazione di lusso.
